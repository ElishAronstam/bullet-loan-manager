# Bullet Loan Manager

## Prerequisites
- Node.js 18+
- npm

## Backend

```bash
cd backend
npm install
npm run dev
```

GraphQL playground available at: http://localhost:4000/graphql

## Frontend

```bash
cd frontend
npm install
npm run dev
```

App available at: http://localhost:3000

## Database

SQLite database (`loans.db`) is created automatically on first backend run via TypeORM `synchronize: true`.
